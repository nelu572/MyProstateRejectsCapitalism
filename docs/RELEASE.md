# 마감 및 빌드 정책

- **최종 개발 마감: 2026-11-11, KST(Asia/Seoul).**
- 구체적인 제출 시각은 미확정이다. 날짜만으로 자정이나 특정 마감 시각을 가정하지 않는다.
- 제출 플랫폼과 빌드 요구사항은 확인 전까지 추정하지 않는다. 관련 작업 시 사용자 또는 공식 제출 안내에서 확인한다.
- 기능 완성도보다 실제 플레이 가능한 빌드를 우선한다. 새 기능은 필요성, 제작 비용과 남은 시간을 고려한다.
- 주요 기능이 연결되면 조기에 실제 빌드를 실행해 문제를 확인한다. 빌드를 마지막 순간까지 미루지 않는다.
- 마감이 가까워질수록 신규 기능보다 안정화, 플레이테스트와 제출 가능 상태 확보를 우선한다. 구체적인 기능 삭제나 범위 축소는 사용자가 결정한다.

## 최소 검증

확인된 대상 플랫폼의 실제 빌드에서 다음을 확인한다.

1. 게임 시작 가능.
2. 주요 진행 흐름 동작.
3. 엔딩 또는 종료 상태 도달 가능.
4. 진행을 막는 치명적인 오류 없음.
5. 실제 빌드에서 실행 확인.

Editor에서의 실행만으로 실제 빌드 검증을 대체하지 않는다. 초기 개발에서 아직 구현되지 않았거나 확인하지 못한 항목은 통과로 기록하지 않는다.

## 결과와 제출

- 빌드 검증 시 대상 플랫폼, 빌드 위치·식별 정보와 확인한 소스 상태(커밋 및 관련 미커밋 변경), 위 항목의 결과와 남은 문제를 간략히 남긴다.
- 빌드 생성·검증 완료를 최종 승인이나 제출 완료로 간주하지 않는다. 외부 업로드·제출은 사용자가 요청하거나 명시적으로 승인했을 때만 수행한다.
- 승인 전 후보 빌드와 복구 가능한 작업 상태를 보존하고, 최종 승인 후 [작업 절차](WORKFLOW.md)에 따라 불필요한 중간 빌드와 검증 산출물을 정리한다. 제출에 필요한 최종 빌드와 재현에 필요한 파일은 보존한다.
