# 기획서 연결

[Notion 기획서 — 내 전립선은 자본주의를 거부한다](https://app.notion.com/p/40ab3e6e776c8042affad02901733c91?source=copy_link)

- **Notion은 기획 내용의 기준**, **Git 저장소는 실제 구현 상태의 기준**이다. 작업 트리의 미커밋 변경도 확인하며, 기획서에 적혀 있다는 이유만으로 구현됐다고 판단하지 않는다.
- 현재 기획은 초기 단계다. 후보, 분위기 참고용 예시, 잠정 규모를 확정 사양이나 구현 지시로 취급하지 않는다.
- 기획서 수정은 사용자가 명시적으로 요청했을 때만 수행한다. 구현에 맞춰 Notion을 자동으로 동기화하지 않는다.
- 매 작업마다 기획서 전체를 읽거나 저장소에 복제할 필요는 없다. 관련 기획 확인이 필요한 작업에서 해당 부분만 참고한다.
- 기획서와 구현에 차이가 있으면 관련 항목과 실제 동작을 간략히 보고한다. 중요한 기획 판단이 필요하면 사용자의 결정을 받은 뒤 진행한다.
- Notion 접근이 불가능하면 접근 제한과 확인하지 못한 범위를 보고한다. 확인하지 못한 내용을 추측해 구현하지 않는다. 그 내용과 무관하게 진행 가능한 요청 범위는 계속 수행한다.
