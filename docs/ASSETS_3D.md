# 3D 에셋 제작과 Unity 전달

Blender 등 외부 3D 제작 도구를 사용하는 작업에 적용한다. 특정 아트 스타일이나 파일 형식을 미리 확정하지 않는다.

## 제작

- 모델의 사용 목적과 요청된 요구사항을 먼저 확인한다. 실제 화면에서의 용도, 크기, 필요한 상호작용 등 작업에 필요한 범위만 확인한다.
- 기존 에셋을 먼저 확인하고 불필요하게 다시 제작하지 않는다.
- 확정되지 않은 디자인을 임의로 최종 확정하지 않는다. 형태와 비율을 먼저 검토한 뒤 세부 작업을 진행한다.
- 필요한 경우 중간 결과를 보여주고 사용자 피드백을 반영한다.

## Unity 통합

- 수정 가능한 제작 원본과 Unity용 최종 산출물을 구분한다. 기존 폴더 구조를 우선하며, 원본·후보를 보관한다는 이유로 모두 `Assets/`에 가져오지 않는다.
- 필요한 항목만 확인한다: 크기·단위, 축·방향, Pivot, 재질, UV, 텍스처와 외부 파일 의존성. 애니메이션이 있으면 리그와 클립도 확인한다.
- 실제 Unity 환경에서 배치 크기, 방향, 외관과 필요한 동작을 검증한다. Editor 작업은 [공통 Unity 규칙](../AGENTS.md#unity-작업)을 따른다.
- Unity `.meta` 파일과 참조 관계를 보존한다. 기존 에셋을 이동하거나 교체할 때 참조가 유지되는지 확인한다.
- 사용하지 않는 외부 에셋이나 관련 없는 파일을 무분별하게 프로젝트에 가져오지 않는다.

## 최종 승인과 정리

- 모델 제작 완료와 사용자 최종 승인은 별개다. 승인 전에는 수정 가능한 원본과 후보 결과물을 보존한다.
- 최종 승인 후 사용하지 않는 임시 결과물과 불필요한 중간 산출물을 정리한다.
- 최종 모델, 필요한 텍스처·재질, 제작 원본 및 재현에 필요한 파일은 보존한다.
- 파일을 제거하기 전에 Unity 참조와 외부 제작 파일의 의존성이 끊기지 않는지 확인한다. 확인하지 못하면 보존하고 보고한다.
- 삭제 안전 규칙은 [작업 절차](WORKFLOW.md#승인-후-정리와-삭제-안전)를 따른다. 정리 자체가 새로운 제작 작업보다 커지지 않도록 한다.
